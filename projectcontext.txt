Project Overview
================================================================================

SH-02 adalah sistem manajemen portfolio untuk LEXA Software House. Sistem terdiri
dari Admin Dashboard yang digunakan untuk mengelola konten dan Public Website
yang digunakan untuk menampilkan informasi.

Scope Pekerjaan:
- Frontend Admin Dashboard (React.js)
- REST API Integration
- Responsive Design
- Loading & Error Handling

Catatan: Frontend public website dikerjakan oleh tim lain, saya fokus pada
Admin Dashboard saja.

================================================================================
TECH STACK
================================================================================

Frontend:
- React.js 18+
- React Router v6 (untuk routing)
- Axios (HTTP client)
- Tailwind CSS (styling)
- Recharts (dashboard charts & visualizations)
- React Hook Form (form management)
- SweetAlert2 atau Modal component (untuk confirmations)

Backend:
- Dikerjakan oleh tim lain
- REST API (akan dikonfirmasi contract-nya)

Tools & Utilities:
- Vite (build tool, lebih cepat dari CRA)
- ESLint (code quality)
- Prettier (code formatting)
- Git (version control)

2. DASHBOARD MODULE
================================================================================

Flow:
  Authenticated User → Dashboard → View Statistics & Charts → Quick Actions

Features:
A. STATISTICS CARDS (4 cards dengan trend)
   - Total Projects
     Display: Angka total | % perubahan dari bulan lalu | Mini trend chart
     Color: Blue
   
   - Completed Projects
     Display: Angka | % perubahan | Mini trend chart
     Color: Green
   
   - In Progress Projects
     Display: Angka | % perubahan | Mini trend chart
     Color: Orange
   
   - Total Clients
     Display: Angka | % perubahan | Mini trend chart
     Color: Purple

B. CHARTS & VISUALIZATIONS
   
   1. Project Overview Chart (Line Chart)
      - X-axis: Months (Jan - Jun atau last 6 months)
      - Y-axis: Number of projects
      - 3 lines: Total Projects, Completed, In Progress
      - Color: Blue, Green, Orange
      - Time filter: 6 Months dropdown
      
   2. Projects by Category (Pie/Doughnut Chart)
      - Categories: Web Development, Mobile Development, System Development, UI/UX Design, Other
      - Show: Percentage & count
      - Colors: Multiple color palette
      - Center text: Total projects count
      
   3. Top Technologies (Horizontal Bar Chart)
      - Technologies: Laravel, React, Flutter, Node.js, Vue.js
      - Values: Percentage (e.g., 80%, 70%, 60%)
      - Show: Technology icon, name, percentage
      - Sorted: Descending by usage
      
   4. Client Satisfaction (Rating Card)
      - Display: 4.9/5 average rating
      - Show: 5 gold stars
      - Additional info: "Based on X Reviews" (jumlah review)
      - Breakdown: Rating distribution (5 star: 27 reviews, 4 star: 4 reviews, etc.)

C. RECENT PROJECTS LIST
   - Show: Last 5-10 projects
   - Columns/Info:
     - Project thumbnail image
     - Project name
     - Client name
     - Status (Completed, In Progress, On Hold)
     - Date (completion date atau start date)
     - Action: View link
   - Pagination: Next page link atau "View All" button

D. QUICK ACTIONS (5 action buttons)
   - Add New Project
   - Add Case Study
   - Add Testimonial
   - Upload Document
   - View Reports
   
   Each button: Icon + Text + Description

Pages:
- / or /dashboard

API Endpoints:
- GET /api/statistics/summary (untuk semua stat cards)
- GET /api/projects/overview (untuk Project Overview chart)
- GET /api/projects/by-category (untuk Projects by Category)
- GET /api/technologies/top (untuk Top Technologies)
- GET /api/client-satisfaction (untuk rating & reviews)
- GET /api/projects/recent (untuk Recent Projects)

API INTEGRATION STRATEGY
================================================================================

Authentication:
- Store JWT token di localStorage atau httpOnly cookie (discuss dengan backend)
- Include token dalam semua API requests (axios interceptor)
- Implement token refresh logic
- Logout saat token expired

Error Handling:
- Centralized error handling via axios interceptor
- Display user-friendly error messages
- Log errors untuk debugging
- Retry logic untuk failed requests (optional)

Loading States:
- Global loading state untuk page transitions
- Component-level loading state untuk data fetching
- Proper skeleton loaders atau spinners

Data Caching:
- Cache data untuk mengurangi API calls
- Invalidate cache saat data berubah
- Consider using React Query untuk advanced caching
