Project Overview
================================================================================

SH-02 adalah sistem manajemen portfolio untuk LEXA Software House dengan
multi-role user system dan team-based access control. Sistem terdiri dari:

1. Admin Dashboard (untuk internal - berbagai roles)
2. Public Website (dikerjakan tim lain)

Scope Pekerjaan:
- Frontend Admin Dashboard (React.js + Better Auth)
- REST API Integration
- Role-Based Access Control (7 roles)
- Team-Based Access (khususnya untuk Magang)
- Responsive Design
- Loading & Error Handling

================================================================================
AUTHENTICATION & AUTHORIZATION SYSTEM
================================================================================

Authentication Library: Better Auth Client
Backend Base URL: https://ppms-backend-api.up.railway.app

SETUP
=====

Dependencies:
npm install better-auth @better-auth/react @better-auth/core

File: src/config/auth.config.js
```javascript
import { createAuthClient } from "@better-auth/react";

export const auth = createAuthClient({
  baseURL: import.meta.env.VITE_API_BASE_URL,
});
```

File: .env.local
```
VITE_API_BASE_URL=https://ppms-backend-api.up.railway.app
VITE_API_TIMEOUT=30000
```

AUTHENTICATION FLOW
===================

1. User Login
   - Better Auth sign in dengan email & password
   - Backend returns session token + user data

2. Session Management
   - Auto-managed oleh Better Auth
   - Token stored securely

3. Token Refresh
   - Better Auth handle auto-refresh
   - Redirect ke login jika token expired

4. Authorization
   - Frontend check user role
   - Show/hide UI berdasarkan permissions
   - Backend juga validate di API

ROLE-BASED ACCESS CONTROL
=========================

User Data Structure (dari backend):
```json
{
  "id": "user-123",
  "email": "user@company.com",
  "name": "User Name",
  "role": "PROJECT_MANAGER",
  "team_id": "team-a",
  "magang_tier": null,
  "assignedProjects": ["proj-1", "proj-2"],
  "permissions": {...}
}
```

Frontend Implementation:
- useAuth hook: provides session & user data
- useRole hook: provides role-based utilities
- RoleGuard component: conditional rendering
- ProtectedRoute: route-level access control

POST   /auth/sign-in              ← Email & password login

GET    /auth/session              ← Get current session
POST   /auth/forgot-password      ← Password reset (optional)
